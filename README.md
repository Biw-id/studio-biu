# Studio Biu — Solusi Pembuatan Website Modern, Cepat & Berkonversi Tinggi

Website resmi **Studio Biu** (`https://studio-biu.netlify.app`), sebuah platform studio digital modern untuk membantu UMKM, profesional, dan bisnis berkembang memiliki kehadiran digital berkelas tinggi dengan kecepatan tinggi (Google PageSpeed 95+) dan integrasi penjualan WhatsApp otomatis.

## 🌟 Fitur Utama

- **Hero Berorientasi Konversi:** Headline tajam bernilai bisnis, badge ketersediaan proyek real-time (*Open for new projects*), dual CTA langsung ke WhatsApp, serta kartu audit arsitektur (PageSpeed 99, Core Web Vitals 0.6s).
- **Pilar Nilai / Why Us:** 4 kartu keunggulan terukur: *Super Cepat & Ringan*, *Desain Mobile-First*, *WhatsApp Ready*, dan *Garansi Bug-Free 30 Hari*.
- **4 Layanan Spesifik (`#services`):**
  1. *High-Converting Landing Page* (Promosi & Iklan)
  2. *Company Profile & Web Bisnis* (Branding & Trust)
  3. *E-Katalog & UMKM Store* (WhatsApp Checkout & Cart Drawer)
  4. *Custom Web App & Dashboard* (Operasional & SaaS)
- **Selected Works / Portofolio Nyata (`#work`):**
  - **KatalogKu Universal E-Catalog** (Live Demo di Netlify)
  - **Padang Panjang Interactive 3D Web** (Three.js WebGL & Audio Visualizer)
  - **Modern Workspace Task Dashboard** (React 18 & Genesis Design System)
  - **Bengkel Management System** (Full-Stack Laravel 11 ERP Case)
- **Alur Kerja Transparan (`#process`):** 4 tahapan jelas (*01. Konsultasi & Brief*, *02. Wireframe & Desain*, *03. Development & Tes*, *04. Peluncuran & Garansi*).
- **Paket Investasi Dinamis (`#pricing`):** Toggle interaktif *Sekali Bayar (Proyek)* vs *Langganan / Maintenance Bulanan* dengan tombol WhatsApp terisi pesan otomatis (*pre-filled*).
- **FAQ Interaktif (`#faq`):** Accordion tanya-jawab seputar waktu pengerjaan, domain/hosting, sistem pembayaran DP 50%, dan hak milik source code 100%.
- **Floating WhatsApp Quick Action:** Tombol melayang di pojok kanan bawah untuk memudahkan calon klien berkonsultasi kapan saja.

## 🛠️ Tech Stack

- **Framework & Tooling:** [Vite 8](https://vitejs.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Interaktivitas:** Vanilla JavaScript (ES6+ Native DOM API)
- **Aset & Ikon:** Inline SVG & WebP/PNG Resolusi Tinggi
- **Deployment:** Netlify Continuous Deployment via GitHub

## 🚀 Menjalankan Secara Lokal

```bash
# 1. Clone repository
git clone https://github.com/Biw-id/studio-biu.git
cd studio-biu

# 2. Install dependencies
npm install

# 3. Jalankan server lokal
npm run dev

# 4. Build untuk produksi
npm run build
```
